# EduTechEx backend

Node.js API for the SAT practice app. Registrations are stored in MongoDB.

## Start

From this folder, run `npm install` and make sure `.env` contains `MONGO_URI` set to your MongoDB connection string and the SMTP settings `EMAIL_HOST`, `EMAIL_PORT`, `EMAIL_USER`, and `EMAIL_PASS`. The backend uses `EMAIL_USER` as the sender by default; set `EMAIL_FROM` if your mail provider requires a separate verified sender address. Set `EMAIL_SECURE=true` if your provider requires implicit TLS on a nonstandard port. Then run `npm start`. The API listens on port 5000 by default; set `PORT` to change it. The server waits for MongoDB before accepting requests.

## Routes

- `GET /api/health` reports whether the API is running.
- `POST /api/sat/registrations` accepts `{ "name", "email", "phone", "curriculum" }` and returns a registration ID.
- `POST /api/sat/registrations/:id/verify` accepts `{ "code": "123456" }` and verifies the one-time code emailed during registration.

The SAT registration and verification screens call these routes. OTPs are generated by the backend, expire after 10 minutes, and allow up to five attempts. Only a keyed hash of the code is stored in MongoDB. SMTP settings must be configured for registration to send email.
